## ✨ Что нового

### 1. ✏️ Редактирование имени пользователя

**Где:** Окно чата → Кнопка редактирования рядом с именем пользователя

**Как использовать:**

1. Откройте чат с пользователем
2. Нажмите на иконку ✏️ рядом с именем
3. Введите новое имя в модальном окне
4. Нажмите "✅ Сохранить"

**API Endpoint:**

- `PUT /api/chats/<chat_id>/name`
- Параметры: `{ "name": "Новое Имя" }`

**Особенности:**

- ✅ Валидация на пустую строку
- ✅ Автоматический trim пробелов
- ✅ Подтверждение успеха
- ✅ Обновление данных после сохранения

---

### 2. 🗑️ Удаление чата

**Где:** Окно чата → Красная кнопка 🗑️ в заголовке

**Как использовать:**

1. Откройте чат с пользователем
2. Нажмите на красную кнопку 🗑️
3. Подтвердите удаление в модальном окне
4. Проверьте информацию (имя, количество сообщений)
5. Нажмите "🗑️ Да, удалить"

**API Endpoint:**

- `DELETE /api/chats/<chat_id>`
- Возвращает количество удаленных сообщений

**⚠️ ВАЖНО:**

- ❌ **Действие необратимо!**
- ❌ Удаляет пользователя из БД
- ❌ Удаляет ВСЕ сообщения чата
- ✅ Требует подтверждение
- ✅ Показывает предупреждение

## 🔧 Технические детали

### Валидация

**Редактирование имени:**

```javascript
// Frontend валидация
if (!editedName.trim()) {
  alert("Имя не может быть пустым");
  return;
}

// Backend trim
body: JSON.stringify({ name: name.trim() });
```

**Удаление чата:**

```javascript
// Двойное подтверждение
// 1. Клик на кнопку → открытие модального окна
// 2. Клик "Да, удалить" → выполнение удаления
```

### Обработка ошибок

```javascript
try {
  const result = await apiClient.updateUserName(chatId, name);
  if (result.success) {
    alert("✅ Имя обновлено успешно!");
    window.location.reload();
  }
} catch (err) {
  alert("❌ Ошибка обновления имени: " + err.message);
}
```

### После удаления

```javascript
if (result.success) {
  alert(
    `✅ Чат удален успешно!\nУдалено сообщений: ${result.deleted.messages_count}`
  );
  // Перенаправление на главную
  window.location.href = "/";
}
```

## 💡 Советы по использованию

### Редактирование имени

✅ **Когда использовать:**

- Пользователь неправильно ввел имя
- Нужно добавить фамилию или уточнение
- Исправление опечаток

❌ **Не рекомендуется:**

- Менять имя слишком часто
- Использовать для заметок (для этого есть отдельные поля)

### Удаление чата

✅ **Когда использовать:**

- Тестовые чаты
- Спам или мошенники
- Дубликаты пользователей
- По запросу пользователя (GDPR)

❌ **Не рекомендуется:**

- Удалять чаты с историей без крайней необходимости
- Удалять активные чаты
