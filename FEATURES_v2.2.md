## 📝 Редактирование сообщений бота

### Функционал

Теперь вы можете изменять все текстовые сообщения, которые отправляет бот пользователям, прямо из админки!

### 8 типов сообщений

1. **Приветствие при первом контакте** (`welcome`)
   - Отправляется когда пользователь впервые пишет боту
2. **Просьба выбрать статус** (`ask_status`)

   - Бот просит пользователя представиться
   - Плейсхолдер: `{name}`

3. **Подтверждение выбора статуса** (`status_selected`)

   - После того как пользователь выбрал статус
   - Плейсхолдер: `{status_name}`

4. **Приветствие при повторном контакте** (`welcome_back`)

   - Когда зарегистрированный пользователь снова пишет /start
   - Плейсхолдеры: `{name}`, `{status_name}`

5. **Подтверждение получения сообщения** (`message_received`)

   - Отправляется после каждого сообщения от пользователя

6. **Сообщение о неподдерживаемом типе** (`unsupported_message`)

   - Если пользователь отправил фото, стикер и т.д.

7. **Просьба сначала выбрать статус** (`need_status`)

   - Если пользователь пишет до выбора статуса

8. **Префикс для сообщений от админа** (`admin_message_prefix`)
   - Добавляется в начало каждого сообщения от администратора
   - Плейсхолдер: `{admin_name}`

### Плейсхолдеры

Специальные метки, которые автоматически заменяются на реальные данные:

- `{name}` - имя пользователя
- `{status_name}` - название статуса
- `{admin_name}` - имя администратора

**⚠️ Важно**: Не удаляйте плейсхолдеры из сообщений! Они нужны для подстановки данных.

### Как использовать

1. Откройте **⚙️ Настройки** в меню
2. Выберите вкладку **📝 Сообщения**
3. Отредактируйте нужное сообщение
4. Нажмите **💾 Сохранить**
5. ✅ Изменения применяются мгновенно (перезапуск бота не требуется!)

## 👥 Управление статусами клиентов

### Функционал

Создавайте, редактируйте и удаляйте статусы для категоризации пользователей.

### Системные статусы

**🔒 Студент** (`student`) и **🔒 Резерв** (`reserve`) - это системные статусы:

- ❌ Нельзя удалить
- ✅ Можно редактировать название и эмодзи
- ✅ Критичны для работы системы

### Пользовательские статусы

Все остальные статусы можно:

- ✅ Добавлять
- ✅ Редактировать (название и эмодзи)
- ✅ Удалять

### Структура статуса

Каждый статус состоит из:

- **Value** - технический идентификатор (только латиница, цифры, подчеркивания)
  - Примеры: `vip_client`, `graduate2025`, `applicant`
  - ❌ Нельзя использовать: `vip-client`, `выпускник`
- **Название** - отображаемое имя (любой текст)
  - Примеры: "VIP Клиент", "Выпускник 2025", "Абитуриент"
- **Эмодзи** - иконка (опционально)
  - Примеры: ⭐, 🎓, 👨‍💼

### Как добавить статус

1. Откройте **⚙️ Настройки** → **👥 Статусы**
2. Прокрутите вниз до формы "Добавить новый статус"
3. Заполните поля:
   - **Value**: `vip` (только латиница)
   - **Название**: `VIP Клиент`
   - **Эмодзи**: `⭐`
4. Нажмите **➕ Добавить статус**
5. ✅ Статус появится в списке и сразу будет доступен в боте!

### Как редактировать статус

1. Найдите нужный статус в списке
2. Нажмите **✏️ Редактировать**
3. Измените название и/или эмодзи
4. Нажмите **💾 Сохранить**
5. ✅ Изменения применяются мгновенно!

### Как удалить статус

1. Найдите статус (не системный!)
2. Нажмите **🗑️ Удалить**
3. Подтвердите действие в модальном окне
4. ✅ Статус удален!

**⚠️ Важно**: Пользователи с удаленным статусом останутся в системе, но их статус станет пустым.

## 🔧 Технические детали

### API Endpoints

**Сообщения:**

- `GET /api/bot-messages` - получить все сообщения

## ⚠️ Важные замечания

### Плейсхолдеры

❌ **НЕ УДАЛЯЙТЕ** плейсхолдеры типа `{name}`, `{status_name}`, `{admin_name}`

Они необходимы для подстановки реальных данных!

### Value статуса

После создания статуса **нельзя изменить** его `value`.

Если нужно изменить - удалите старый и создайте новый.

### Системные статусы

**student** и **reserve** - критичные статусы:

- Используются в логике бота
- Нельзя удалить
- Можно изменить только отображение

### Удаление статуса

При удалении статуса пользователи с ним **не удаляются**.

Их статус просто становится пустым.

## 🎯 Рекомендации

### Тексты сообщений

✅ **Хорошо:**

- Короткие и понятные
- С эмодзи для визуального разделения
- Вежливые и дружелюбные

❌ **Плохо:**

- Слишком длинные (более 200 символов)
- Без структуры
- Грубые или формальные

### Статусы

✅ **Хорошо:**

- Понятные названия ("Абитуриент", "Родитель")
- Релевантные эмодзи (🎓, 👨‍👩‍👧)
- Логичная структура

❌ **Плохо:**

- Слишком специфичные ("Абитуриент-2025-осень-платно")
- Дублирующие друг друга
- Слишком много статусов (более 10-12)
