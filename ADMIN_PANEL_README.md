# Telegram Bot Admin Panel - React.js

## 📋 Описание

Современная веб-админка для управления Telegram ботом с адаптивным дизайном. Позволяет администраторам просматривать чаты с клиентами, отвечать на сообщения, управлять статусами пользователей и выполнять массовые рассылки.

## ✨ Основные возможности

### 1. **Дашборд**
- 📊 Общая статистика по чатам
- 🔔 Количество непрочитанных сообщений
- 📈 Распределение пользователей по статусам
- 🎨 Визуальные графики и диаграммы

### 2. **Управление чатами**
- 💬 Просмотр всех активных чатов
- 🔍 Поиск по имени пользователя
- 🏷️ Фильтрация по статусам
- ⏰ Сортировка по времени или непрочитанным
- 📬 Счетчик непрочитанных сообщений
- ✅ Автоматическая пометка как прочитанное

### 3. **Окно чата**
- 📱 История всех сообщений
- ⚡ Автообновление каждые 3 секунды
- 💬 Отправка сообщений клиентам
- 🏷️ Изменение статуса пользователя
- 👤 Указание имени администратора
- 📅 Группировка сообщений по датам

### 4. **Массовая рассылка**
- 📢 Отправка сообщений всем пользователям
- 🎯 Выборочная рассылка по группам (студенты, абитуриенты, родители)
- 📊 Статистика отправки (успешно/ошибки)
- ✅ Подтверждение перед отправкой

### 5. **Уведомления**
- 🔔 Звуковое оповещение о новых сообщениях
- 🌐 Browser notifications
- 🔴 Визуальные индикаторы непрочитанных

## 🚀 Установка и запуск

### 1. Установка зависимостей
```bash
cd app
npm install
```

### 2. Настройка API
Убедитесь, что backend запущен на `http://0.0.0.0:80/api`

При необходимости измените URL в файле:
```javascript
// src/api/client.js
const API_BASE_URL = 'http://0.0.0.0:80/api';
```

### 3. Запуск приложения
```bash
npm start
```

Приложение откроется в браузере по адресу: `http://localhost:3000`

### 4. Сборка для production
```bash
npm run build
```

## 🔧 Настройка

### Интервалы автообновления

В файле `src/constants/statuses.js`:

```javascript
export const UPDATE_INTERVALS = {
  CHAT_LIST: 5000,      // 5 секунд - список чатов
  CHAT_HISTORY: 3000,   // 3 секунды - история чата
  DASHBOARD: 30000      // 30 секунд - дашборд
};
```

### Имя администратора

При первом использовании введите свое имя в поле "Ваше имя" в окне чата. Оно сохранится в localStorage и будет использоваться во всех сообщениях.

### Browser Notifications

При первом запуске браузер запросит разрешение на показ уведомлений. Рекомендуется разрешить для получения оповещений о новых сообщениях.

## 🎯 Использование

### Просмотр чатов
1. Перейдите в раздел **"Чаты"** через боковое меню
2. Используйте поиск для быстрого нахождения нужного пользователя
3. Фильтруйте по статусу (студент, абитуриент и т.д.)
4. Сортируйте по времени или непрочитанным сообщениям

### Ответ на сообщение
1. Нажмите на чат в списке
2. История сообщений загрузится автоматически
3. Введите ответ в поле внизу
4. Нажмите кнопку отправки (📤)

### Изменение статуса клиента
1. Откройте чат
2. Нажмите на кнопку текущего статуса сверху справа
3. Выберите новый статус из выпадающего меню

### Массовая рассылка
1. Перейдите в раздел **"Рассылка"**
2. Выберите целевые группы (или оставьте пустым для всех)
3. Введите текст сообщения
4. Укажите имя отправителя
5. Нажмите **"Отправить рассылку"**
6. Подтвердите действие
7. Просмотрите статистику отправки

## 📊 API Endpoints

Админка использует следующие API endpoints:

### Статистика
- `GET /api/health` - проверка работы API
- `GET /api/stats` - общая статистика
- `GET /api/statuses` - список доступных статусов

### Чаты
- `GET /api/chats` - список всех чатов
- `GET /api/chats/:chatId` - история конкретного чата
- `POST /api/chats/:chatId/send` - отправка сообщения
- `POST /api/chats/:chatId/mark-read` - пометка как прочитанное

### Статусы пользователей
- `GET /api/chats/:chatId/status` - получить статус
- `PUT /api/chats/:chatId/status` - изменить статус

### Рассылка
- `POST /api/broadcast` - массовая рассылка
